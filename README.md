# Shifter-Converter

A program to convert .Shifter files to .ics files.

## What is a .Shifter file?

A .Shifter file is a file generated by the app [Shifter Calendar](https://play.google.com/store/apps/details?id=com.lrhsoft.shiftercalendar). An app for managing shift work. It makes it easy to define the times a certain shift is at and then input your whole calendar into the app by just clicking on the type of shift per day. Below is an example of a Shifter calendar:

![Shifter calendar](/Shifter_file.webp)

## How does it work?

![Demo gif](/demo.gif)

To install the program, just use pip:

```shell
pip install shifter-converter 
```

Then you are presented with three options: converting a file, validating a file, or quiting the program. If you choose the first option you can select the file and then an output directory and then you get your .ics version of the .Shifter file.

## How can I test if it works?

This repository contains a `Testing.Shifter` file that you can use to test out the program
